# project preferences

- do not create hosted sites unless explicitly requested.
- commit messages must be entirely lowercase and start with a lowercase scope tag, such as `app:`.
- use one broad, general subject describing the overall area of change.
- keep wording terse and programmatic; avoid leading articles and conversational sentences.
- add details only when useful, as clear, concise bullets after a blank line.
- never add trailers, co-author tags, or generated-with lines.
